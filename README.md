## Alat Pemberi Pakan Ikan Hias Otomatis Dilengkapi Monitoring Kekeruhan dan Suhu Air Pada Akuarium Berbasis Arduino Uno
Proyek sistem pemberi pakan ikan hias otomatis berbasis Arduino UNO yang dilengkapi pemantauan suhu dan kekeruhan air akuarium. Sistem menggunakan sensor DS18B20 untuk mengukur suhu air, sensor turbidity untuk mendeteksi kekeruhan, serta modul RTC DS1307 untuk mengatur jadwal pemberian pakan. Informasi hasil pengukuran ditampilkan melalui LCD 20×4.

## Fitur
  • Monitoring suhu air menggunakan sensor DS18B20.

  • Monitoring kekeruhan air menggunakan sensor turbidity.

  • Tampilan suhu, kondisi air, dan waktu melalui LCD 20×4.

  • Peringatan kondisi suhu dan kekeruhan air berdasarkan batas yang ditentukan.

  • Pemberian pakan ikan otomatis sesuai jadwal menggunakan motor servo.

## Teknologi
  • Mikrokontroler: Arduino UNO

  • Bahasa Pemrograman: C++ (Arduino framework)
